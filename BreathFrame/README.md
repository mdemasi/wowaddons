# BreathFrame

WoW addon that draws a translucent blue border around the screen while your breath is draining underwater.

- Fades in when breath starts draining
- Starts pulsing slowly at 50% breath, faster as it approaches 0%
- Blends to red and grows toward the screen center below 40%
- Draws behind all UI elements

Install: copy this folder to `Interface/AddOns/BreathFrame/`, then `/reload`. Test with `/breathframe test`.
